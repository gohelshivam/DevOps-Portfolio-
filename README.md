# Shivam Gohel — DevOps Portfolio

## Run locally

Open `index.html` in a browser.

## Deploy on GitHub Pages

1. Create a GitHub repository, e.g. `shivam-portfolio`.
2. Upload `index.html`, `styles.css`, and `script.js`.
3. GitHub → Settings → Pages → Deploy from branch → `main` / root.
4. Your site will be available at:
   `https://gohelshivam.github.io/shivam-portfolio/`

## Before publishing

- Replace `shivam.gohel.dev@example.com` with your real email.
- Update project links when repositories are public.
- Add certificate URLs if desired.
- Verify your LinkedIn URL.
